# Yasin TV Launcher

## Сборка APK

1. Загрузите в корень репозитория архив `YasinWidgetLauncher-build-ready.zip` (или `YasinWidgetLauncher.zip`) через **Add file → Upload files → Commit changes**.
2. Откройте вкладку **Actions** и выберите **Build Yasin TV Launcher APK**.
3. Нажмите **Run workflow** (или дождитесь автоматического запуска после загрузки архива).
4. После успешной сборки откройте запуск и скачайте артефакт **YasinTVLauncher-debug**. Внутри будет `app-debug.apk`.

## Параметры проекта

- Application ID: `com.aktobe.yasinlauncher`
- minSdk: 24 (Android 7.0)
- compileSdk / targetSdk: 34
- JDK: 17
- Gradle: 8.2
